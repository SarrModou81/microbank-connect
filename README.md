# MicroBank Connect

Plateforme de gestion bancaire et de microfinance — projet de fin de module Développement Front End Angular v20 (MIAGE 1 - ISI KM).

## Stack technique

- Angular v20 (composants standalone, signals, routing avec lazy loading)
- Bootstrap 5 + Font Awesome
- json-server (API REST mockée)
- TypeScript (strict mode)

## Prérequis

- Node.js 18+
- npm

## Installation

```bash
git clone https://github.com/SarrModou81/microbank-connect.git
cd microbank-connect
npm install
